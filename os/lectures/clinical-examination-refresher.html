One-hour facilitator guide

Core Physical Examination Refresher

Learners re-teach a core examination skill, observe one another closely, and improve the next attempt.

Start the sessionBack to desk

Set the standard

A demonstration is useful only when the learner can see the sequence, name the purpose, and recognize an adequate result.

Ask each teaching pair to identify the decision their assigned maneuver informs.

Facilitator note

Keep the opening brief. The session should be dominated by demonstration, observation, feedback, and another attempt.

Run of show

  1. 0-5 minutesFrame the purpose and assign observer roles.
  2. 5-15 minutesPairs prepare a short teaching demonstration.
  3. 15-40 minutesPeer re-teaching rounds with observation and feedback.
  4. 40-52 minutesRepeat the hardest maneuver after feedback.
  5. 52-60 minutesDebrief and commit to one change.

Observer jobs

Sequence

Could you reproduce the steps in the same order?

Positioning

Were the patient and examiner positioned for a reliable maneuver?

Purpose

Did the teacher explain what the maneuver tests?

Finding

Did the teacher define what counts as an interpretable result?

Feedback that changes performance

  1. Name one observable strength.
  2. Name one step that reduced clarity or reliability.
  3. Offer one specific correction.
  4. Repeat that part immediately.
Reveal the feedback stem

“When you did ___, I observed ___. On the next attempt, try ___ so that ___.”

Debrief

Teaching

What made a demonstration easy to follow?

Examining

Which small change most improved the maneuver?

Feedback

What made a correction feel usable?

Transfer

What will you do differently with the next patient?

After class

  • Which maneuver produced the most useful discussion?
  • Where did learners need more structure?
  • What should change before the next run?
